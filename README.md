# fabrica

Simple app for tailors and seamstress.

## Features

- Upload fabric and style photo.
- Enter body measurements.
- See cloth needed (yards).
- See total estimated cost.
- Print only important summary sections.

## How to run

```bash
npm install
npm run dev
```

## How to use

1. Upload fabric image.
2. Upload style image (optional).
3. Enter measurements and cloth available.
4. Pick recommended style.
5. Check summary and print.
